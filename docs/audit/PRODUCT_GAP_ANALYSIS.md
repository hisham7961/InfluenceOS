# InfluenceOS — Product Gap Analysis

**Audit HEAD:** `85b6c852` · Council: Influencer-Marketing CTO / Agency & Campaign Ops (B1), UGC / Rights / Gifting (B2), Creator-CRM / Executive / Global (B3), Finance / Analytics (B4), Product-SaaS / 2026 Market Benchmark (B5). Current-state claims proven from schema + services + web pages.

## What exists today (proven, and genuinely strong)
The 28-model schema is **strong on the back half of the lifecycle**: Influencer 360 (profile, social accounts, notes threaded/pinned/authored, tags, relationship pipeline `PROSPECT→…→BLACKLISTED` global + per-brand, follower snapshots, audience health), versioned scripts/briefs (`ScriptReference` + `ScriptReferenceVersion`), campaign roster with deal types (PAID/FREE/GIFTED/PAID_PLUS_GIFTED — money exact `Decimal`), deliverables with a status lifecycle, content monitoring (BullMQ worker every 30 min; YouTube/X auto-sync), metrics snapshots, costs/expenses, reports (campaign/influencer/brand/content/spend + CSV), calendar, notifications, admin audit log. Metric **provenance** (`dataSource`) is modelled.

## The shape of the gap
InfluenceOS is a strong **influencer-post monitoring CRM**. It is weak or empty on the **front of the funnel** (sourcing, shortlist, negotiation, contracts) and the **middle** (content drafting → review → revision → approval, usage rights, seeding logistics). Grep over `src` returns **zero** hits for `shortlist|application|sourcing|contract|usage-right|revision|rate-card|whitelist|exclusiv|territory|takedown|shipment|courier`.

## Explicitly REJECTED as unnecessary (avoid bloat for a focused internal tool)
Creator self-service **application portal** (violates ADMIN/STAFF-only design — a staff-facing shortlist board is the in-scope alternative); public **creator-discovery marketplace/DB**; **payout/payment processing** (keep operational status only, not a payments rail); **AI creator-matching**; **affiliate/link tracking**; opportunity/deal **forecast pipeline**; **email-inbox sync**; **custom-field engine**; separate **Agency** entity; **e-signature**; **territory hierarchy**; **regional-team scoping** (single-org); MFA is a P3 nice-to-have, not core.

## Global-ops verdict
Brand + language scoping adequate. Real defect = multi-currency aggregation (#4). **Timezone entirely absent** (no tz field; "overdue/today" computed in server UTC) — OPTIONAL P3 for a single-market KWD operation. Country/`targetMarket` are free text — OPTIONAL P4 to normalize. Do **not** add regional-team scoping.
