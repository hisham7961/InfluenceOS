# النسخ الاحتياطي — دليل سريع

## شو بينحفظ؟

سكربت واحد `scripts/backup.sh` بياخد كل ليلة:

1. **قاعدة البيانات** كاملة (كل المؤثرين والحملات والمحتوى والأرقام).
2. **كل الملفات المرفوعة** (الصور، الفيديوهات، الستوريز، الفواتير).
3. **نسخة خارج السيرفر** (إذا حطّيت بيانات حساب تخزين خارجي)، ومشفّرة بكلمة سر إنت بتختارها.
4. **اختبار استرجاع** مرة بالأسبوع (يوم الجمعة): بيرجّع آخر نسخة بقاعدة بيانات مؤقتة ويتأكد إنها سليمة، وبعدين بيمسحها.

آخر نسخة ناجحة بتبيّن بالبرنامج: **الإعدادات ← المنصة ← النسخ الاحتياطي**. إذا مرّ أكثر من 36 ساعة بلا نسخة بيطلع تحذير.

## التشغيل على السيرفر (مرة وحدة)

```bash
cd /opt/influenceos        # أو مكان المشروع عندك
scripts/backup.sh --restore-test     # تجربة أولى يدوية
crontab -e
# وأضف هالسطر (كل ليلة الساعة 2:30):
30 2 * * *  cd /opt/influenceos && scripts/backup.sh >> /var/log/influenceos-backup.log 2>&1
```

## النسخة خارج السيرفر (مهم جداً)

نسخة موجودة بس على نفس السيرفر بتروح إذا راح السيرفر. أضف بملف `.env`:

```
BACKUP_S3_BUCKET="اسم-الباكت"
BACKUP_S3_ENDPOINT="رابط-الخدمة"
BACKUP_S3_ACCESS_KEY_ID="..."
BACKUP_S3_SECRET_ACCESS_KEY="..."
BACKUP_ENCRYPTION_PASSWORD="كلمة سر طويلة"
```

أي خدمة متوافقة مع S3 بتشتغل (Backblaze B2 أو Cloudflare R2 أو AWS أو Wasabi).
**احفظ كلمة سر التشفير بمكان ثاني**؛ بدونها ما بتقدر تفتح النسخة.

اختياري: `BACKUP_HEALTHCHECK_URL` (مثلاً من Healthchecks.io) بيبعتلك تنبيه إذا فشلت النسخة أو ما اشتغلت أصلاً.

## قبل كل تحديث

```bash
scripts/backup.sh --db-only
```

## حماية الملفات من الحذف الخطأ

البرنامج بينظّف الملفات اللي ما إلها سجل. هلق صار:
- ما بيحذف فوراً: بينقل الملف لـ `quarantine/` وبيحذفه بعد 30 يوم.
- إذا لقى إنو أغلب الملفات فجأة بلا سجلات (قاعدة بيانات غلط أو مسترجعة) **بيوقف ولا بيلمس شي**.
- إذا رجع السجل (بعد استرجاع نسخة) بيرجّع الملف لمكانه تلقائياً.
- وقت الاسترجاع أطفِ التنظيف من **الإعدادات ← المنصة ← Flags ← `file_cleanup`** لحتى تخلص، وبعدين رجّعه.
